  1. A SimplePay kereskedői felületén (Azonosítók / Fiókbeállítások) másold ki a Merchant ID-t és a titkos kulcsot, és add meg fent.
  2. Add meg az IPN URL-t a SimplePay felületén is, enélkül a háttér-értesítések nem érkeznek meg.
