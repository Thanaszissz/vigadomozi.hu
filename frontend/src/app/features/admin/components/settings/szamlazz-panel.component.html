ℹ️ Beállítás a Számlázz.hu felületén

  1. A Számlázz.hu fiókodban (Beállítások → Számla Agent) kapcsold be a Számla Agent használatát, és generálj Agent kulcsot.
  2. Másold be a kulcsot fent, válaszd ki a jegyekre vonatkozó ÁFA kulcsot, és mentsd a beállításokat.
  3. Ellenőrizd a kapcsolatot, majd a pénztárban próbálj ki egy számlázott eladást. Az ÁFA kulcsnak egyeznie kell a NAV beállításnál megadottal.
  4. A kiállított számlák PDF-je a szerveren is tárolódik, a pénztárban az eladás után letölthető.
